# Segara Notes

Catatan bergaya Notion dengan UI **shadcn/ui** + Tailwind CSS v4.

## Stack UI

- React 19 + Vite
- Tailwind CSS v4 (@tailwindcss/vite)
- shadcn/ui (new-york): Button, Dialog, Sheet, Command, Tabs, Card, dll.
- Brand teal Segara lewat CSS variables OKLCH

## Jalankan

```bash
npm install
npm run db:migrate
npm run dev:api
npm run dev
```
